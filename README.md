# Maple & Mug Café

A professional, responsive frontend application built for the fictional Maple & Mug Café.

## Tech Stack

- **Framework:** React + Vite
- **Routing:** React Router
- **Styling:** CSS3 (Variable-driven design)
- **Deployment:** Vercel (Ready)

## Features

- Dynamic Menu (Data-driven)
- Professional Gallery grid
- Responsive Mobile-First design
- Form validation
- Custom 404 handling

## Getting Started

1. Install dependencies: `npm install`
2. Run development server: `npm run dev`
